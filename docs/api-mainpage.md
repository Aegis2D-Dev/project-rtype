# R-Type API reference

Reference of the game's headers (`game/include/rtype/`), generated by Doxygen from the
source comments. Engine types (`aegis2d::ecs::Registry`, components, systems...) are
documented in the [engine API reference](https://aegis2d-docs.pages.dev/api/).

For guides, the architecture and the gameplay overview, see the
[documentation site](https://rtype-docs.pages.dev/).

| Header | Contents |
|---|---|
| `rtype/server_game.hpp` | `rtype::ServerGame`: the world, its systems in tick order, the players |
| `rtype/entities.hpp` | Creation of players, missiles and Bydos with their components |
| `rtype/layers.hpp` | Collision layers and masks: who can hit whom |
| `rtype/tuning.hpp` | Gameplay values: play area, speeds, sizes, health, lives, scores |
